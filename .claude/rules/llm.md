# LLM rules — модели, промпты, кэш, стоимость

## Единственная дверь

`packages/llm/src/client.ts` — **единственный** модуль, импортирующий `@anthropic-ai/sdk`.
Стадия, коннектор или `apps/web`, зовущие SDK напрямую, — дефект, и он ловится тестом
(`packages/llm/src/entrypoint.test.ts`), потому что правило без гейта протухает.

Всё остальное разговаривает с `LlmGateway` из `packages/core`. Это же и делает возможным
офлайн-прогон: gateway подменяем, SDK — нет.

## Формы API, которые легко переврать по памяти

Проверено живым вызовом 2026-08-25, каждый пункт — по факту чьей-то ошибки:

- **ID модели без датного суффикса.** `claude-sonnet-5-20251114` — старая форма, 404.
- `thinking: { type: "adaptive" }`. **`budget_tokens` на 5-й серии возвращает 400.**
- Глубина задаётся `output_config.effort` (`low`…`max`), а не бюджетом токенов.
- Structured output — `output_config.format` + `zodOutputFormat`. Устаревшее
  `output_format` — не оно.
- **Prefill ассистента возвращает 400.** Форма ответа задаётся схемой, а не затравкой.
- Citations API **несовместим** с `output_config.format`. Поэтому привязка к источнику
  сделана через `claims[].quote` — что вдобавок проверяется детерминированно и бесплатно.

Цены (USD за 1M токенов) живут в `packages/llm/src/pricing.ts`, а не здесь: два списка цен
разъезжаются. Модель без известной цены роняет вызов **до** траты денег — это намеренно.

## Модель выбирает профиль

`profile.llm.<stage>.model` и `.effort`. Каскад — продуктовое решение темы, а не свойство
кода: дорогая тема может писать Opus'ом, дешёвая — Sonnet'ом, и это правка одной строки в
профиле, а не в `packages/`.

## Антигаллюцинация — три рубежа, и они не взаимозаменяемы

1. **Схема требует ≥2 `claims`, каждое с дословной цитатой.** Нет claims — нет карточки.
2. **Детерминированный верификатор ($0):** нормализация пробелов, кавычек и тире, затем
   `sourceText.includes(quote)`. Провалилась хоть одна цитата → `evidenceOk=false`, карточка
   не идёт в выпуск. Ловит самый частый класс галлюцинаций и стоит ноль.
3. **LLM-верификатор:** цитата есть, но подтверждает ли она утверждение.

**Композитор видит только валидированный JSON карточки, а не исходную статью.** Он физически
не может добавить факт, которого нет в claims. Это архитектурная гарантия; просьба в промпте
такой гарантией не является. Правка, дающая `compose` доступ к сырому тексту источника,
отменяет её — и это не оптимизация, а смена продуктового контракта.

## Кэш

Префиксный: изменение одного байта инвалидирует всё после него. Отсюда правила, нарушение
которых не падает, а просто делает прогон втрое дороже:

- порядок рендера `tools → system → messages`, максимум 4 брейкпоинта;
- минимальный кэшируемый префикс ~1024 токена, **у Haiku выше — проверять измерением**;
- ни `Date.now()`, ни `cycleId`, ни id кандидата в `system`. Только в `user`, после
  брейкпоинта;
- JSON сериализуется с сортировкой ключей.

Гейт: `cache_read_input_tokens` на повторном прогоне **> 0**. Ноль означает тихий
инвалидатор в префиксе — это дефект, а не особенность.

## Стоимость

`costs/baseline.json` — стоимость эталонного прогона, измеренная, а не оценённая
(`"status": "measured"`). Эпик с `costs_llm: true` обязан приложить `pnpm cost:report`,
назвать дельту и обновить baseline **в том же PR** (DoD #6). Рост >20% без причины — находка.

Метка `llm-costs` заперта: два параллельных обновления baseline дают число, которого не было
ни в одном прогоне.

`BudgetGuard` при превышении `maxRunCostUsd` **завершает стадию тем, что успела**, а не
роняет прогон: выпуск из пяти карточек лучше отсутствия выпуска.

Реплей фикстуры сообщает нулевую стоимость — намеренно. Правдоподобное число здесь заставило
бы `cost:report` описывать прогон, которого не было.

## Golden-набор

`pnpm golden` гоняет пайплайн по замороженным входам и проверяет **структуру, а не слова**.
Побайтовый дифф выпуска не может быть гейтом: модель недетерминирована. Он — материал для
человека, ассерты — то, что машина может честно проверять.

Обязателен для эпика с `touches_output: true`, вместе с диффом выпуска в отчёте (DoD #5).

**`golden:update`, сделанный «чтобы позеленело», — критическая находка на ревью,** а не
рутина. Ассерт, который переписали под новый результат, перестаёт быть ассертом.

Ловушка, уже пойманная на E-001: ассерт, не показанный красным ни на одной диверсии, — не
гейт. Подмени данные в фикстуре; ассерт остался зелёным — значит, он ничего не проверяет.

## Что нельзя из агентской сессии

Живой вызов модели за деньги — это `--record` и прогон без `--fixtures`. Оба блокируются
`live-effects-guard.sh`. Готовь команду, отдавай владельцу, не обходи.
